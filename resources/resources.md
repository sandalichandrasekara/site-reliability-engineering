# SRE Learning Resources

A practical resource list for growing from DevOps into Site Reliability Engineering (SRE)

## Core Technical Skills

### Linux, networking, and scripting

- Linux processes, services, CPU/memory, disk, permissions, logs, and systemd.
- DNS, TCP/IP, HTTP/HTTPS, TLS, load balancing, and network troubleshooting.
- Bash and Python for operational automation.

Resources:
- Linux Journey: https://linuxjourney.com/
- Linux command-line tutorials: https://ubuntu.com/tutorials/command-line-for-beginners
- Julia Evans' networking zines: https://wizardzines.com/
- Python tutorial: https://docs.python.org/3/tutorial/
- Bash manual: https://www.gnu.org/software/bash/manual/

### Kubernetes and cloud infrastructure

- Pods, Deployments, Services, Ingress, ConfigMaps, Secrets, requests/limits, probes, scheduling, and RBAC.
- Troubleshooting CrashLoopBackOff, pending pods, failed deployments, and networking issues.
- HPA/KEDA, autoscaling, resource capacity, Terraform, and cloud reliability.

Resources:
- Kubernetes tutorials: https://kubernetes.io/docs/tutorials/
- Kubernetes concepts: https://kubernetes.io/docs/concepts/
- KEDA documentation: https://keda.sh/docs/
- HashiCorp tutorials: https://developer.hashicorp.com/tutorials
- AWS Architecture Center: https://aws.amazon.com/architecture/
- Azure Architecture Center: https://learn.microsoft.com/azure/architecture/

### Observability and performance

- Metrics, logs, traces, dashboards, actionable alerts, and alert fatigue.
- PromQL, latency percentiles (p50/p95/p99), service health, and distributed tracing.
- OpenTelemetry instrumentation and telemetry pipelines.

Resources:
- Prometheus documentation: https://prometheus.io/docs/
- PromLabs: https://promlabs.com/
- Grafana tutorials: https://grafana.com/tutorials/
- OpenTelemetry documentation: https://opentelemetry.io/docs/
- Google Cloud Tech YouTube channel: https://www.youtube.com/@GoogleCloudTech

### SRE principles and system design

- SLIs, SLOs, SLAs, error budgets, and alerting based on user impact.
- Incident response, escalation, blameless postmortems, and corrective actions.
- Capacity planning, disaster recovery, graceful degradation, redundancy, and dependency failures.

Resources:
- Google SRE resources: https://sre.google/resources/
- Site Reliability Engineering book (free online): https://sre.google/sre-book/table-of-contents/
- The SRE Workbook (free online): https://sre.google/workbook/table-of-contents/
- Google Cloud Architecture Framework: https://cloud.google.com/architecture/framework
